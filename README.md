# Airport CRMS — Systems Analysis and Design Assignment

This repository contains the complete supporting materials for the
INSY6211 Assignment 2 submission: a Systems Analysis and Design study
of an Airport Customer Relationship Management System (CRMS) and a
companion case study of a sales workflow at Reciprocal Sales Corporation.

## Contents

- **`docs/`** — The submitted document in Apple Pages and exported PDF form.
- **`diagrams/`** — Source code (Mermaid Markdown and MS Visio) and rendered exports for all
  diagrams in the document: the ERD, application flow, UML activity
  diagram, and UML domain class diagram.
- **`mockups/`** — Editable Sketch source and PNG/PDF exports of all
  user-interface mockups produced for Question 3.2, including style-guide
  artboards and the iOS application icon.
- **`references/`** — Zotero reference library export (CSL JSON), covering
  every source cited in the document.

## How to read the document

The primary deliverable is `docs/INSY6211 Assignment 2.pdf`. Every figure
referenced in that document corresponds to a file in `mockups/exports/` or
`diagrams/renders/`. Diagram source code is included as an addendum to the
document itself; the source files in `diagrams/` are provided for editing
and re-rendering.

## Tooling

- **Document**: Apple Pages
- **Diagrams**: Mermaid (rendered via mermaid.live) and Lucidchart for UML Activity diagram and MS Visio export
- **Mockups**: Sketch (macOS)
- **References**: Zotero with CSL JSON export
- **Version control**: Git with Git LFS for binary assets
